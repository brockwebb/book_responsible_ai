# Task: Document map — scripts/build_map.py → book/book_map.yaml

The map is the single build input for the Typst PDF and the validation gate for the
whole pipeline. Derived, never hand-edited; `book/*.md` prose stays source of truth.

## Build
1. `scripts/build_map.py` (stdlib + PyYAML only). Parses:
   - `book/alphabet.md` — structure is perfectly regular per letter:
     `## <L> is for <Title>` → image directive (path) → `> koan` → `**definition**`.
     Extract: letter, title, koan (plain text, no `>`), definition (plain text,
     no `**`), facer path. Derive lineart path from letter + actual files present in
     `book/images/lineart/` (extension-agnostic — the lineart task may change formats).
   - Front/back section order from `book/myst.yml` toc + the section headings inside
     front-matter.md / back-matter.md.
2. Output `book/book_map.yaml`:
   ```yaml
   meta: {title, subtitle, author, copyright_year: 2025, published_year: 2026, license: CC-BY-4.0}
   front: [ordered section ids]
   letters: [{letter, title, koan, definition, facer, lineart} × 26]
   back: [ordered section ids]
   ```
3. **Validation — script exits nonzero with a named failure if any check fails:**
   - exactly 26 letter records, letters a–z each exactly once, in order
   - every facer and lineart file exists on disk
   - no empty koan, definition, or title
   - no duplicate image paths
4. `book_map.yaml` is generated output → gitignore it (same policy as keyword_index.md)
   and have the PDF build regenerate it every run. The script is committed; the
   artifact is not.
5. Register script as artifact / ResearchTask in Seldon; close on completion.
