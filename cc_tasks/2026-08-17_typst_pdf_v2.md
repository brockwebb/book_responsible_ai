# Task: Typst PDF v2 — the real book layout

Supersedes the MyST typst export from batch 1 (that 47 MB / 74 pp PDF was a pipeline
test, not the book). This is a standalone Typst document consuming `book_map.yaml`
(Typst reads YAML natively via `yaml()` — no codegen step).

## Files
- `book/pdf/main.typ` (+ helper .typ files as needed)
- `scripts/build_pdf.sh` (or extend build_map.py): regenerate map → validate →
  `typst compile` → `book/exports/overresponsible-ai-handbook.pdf`
- Remove the `exports:` typst block from `book/myst.yml` and update README build
  instructions: `myst build --html` = web, `scripts/build_pdf.sh` = PDF. One PDF path
  only; document why in a comment.

## Page architecture (mixed orientation, deliberate)
- **Portrait, US Letter:** cover (full-bleed cover.jpg), all front matter, letter-grid
  index, afterword, compendium, colophon, coloring section.
- **Landscape, US Letter:** the 26 letter pages ONLY.

## Letter page spec (the core design)
- Left half: facer image full-bleed (art is 2:3 ≈ 0.667; half-landscape is 5.5×8.5 ≈
  0.647 — bleed/crop the sliver, do not letterbox, do not distort).
- Right half: the koan ONLY, centered in generous white space, serif italic, sized for
  ~40–60 words. No title, no definition, no page furniture beyond a small page number
  and a small "⌂" link to the grid index. The poster is the loud layer; the right page
  is the quiet layer. Do not "balance" it by adding content.
- Each page gets a named label/destination for links + a PDF bookmark ("A — Alignment").

## Navigation
- **Letter-grid index** (portrait, after front matter): 26 large typographic letters
  in a grid, each an internal link to its letter page. Typographic, NOT thumbnails —
  the posters' baked-in text turns to noise at grid size. Style: bold display serif or
  the closest system font to the cover's lettering; restrained, one accent color
  sampled from the cover.
- **PDF outline/bookmarks:** full tree — front sections, all 26 letters, back
  sections, coloring pages.
- Section TOC in front matter is already text-only (prior task) — link its entries.

## Coloring section
- Portrait. One-page intro (existing coloring-pages.md prose), then one lineart per
  page, full page, zero chrome — these are for printing at home. Consume whatever
  format the lineart task produced (SVG or PNG; typst handles both).

## Acceptance
- Total PDF ≤ ~25 MB (facer JPEGs ~11 MB + optimized lineart + text).
- Spot-render at 300 DPI: cover, letter page A and M, grid page, one coloring page —
  attach to RESULT.
- All grid links and bookmarks jump correctly (test in at least two viewers, e.g.
  Preview + a browser).
- `seldon verify --fix`; register + close ResearchTask.
- Do NOT touch Zenodo. The PDF goes to Brock for the full read-through gate first.
